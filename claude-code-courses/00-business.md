# 00. Бизнес-пакет: как продавать курсы по Claude Code

## 1. Позиционирование
**Обещание:** «Из пользователя чата — в оператора ИИ-агента, который реально выполняет работу на вашем компьютере и в вашем проекте».

**Отличие от «ещё одного курса по ChatGPT»:**
- Claude Code работает с файлами, терминалом, git, браузером, внешними сервисами — результат это готовые артефакты, а не текст в чате.
- Каждый урок заканчивается рабочим результатом (файл, сайт, скрипт, отчёт, PR).
- Три уровня — понятный путь роста, апсейл между ступенями.

**Три сегмента:**
| Уровень | Боль | Триггер покупки |
|---|---|---|
| Старт | «Все говорят про ИИ-агентов, я не понимаю с чего начать, боюсь терминала» | Страх отстать, желание автоматизировать рутину |
| Практик | «Использую, но хаотично: то работает, то нет, контекст теряется» | Нужны стабильность, стандарты, скорость |
| Профи | «Как внедрить в команду, CI, безопасность, измерить эффект» | Бюджет компании, KPI по скорости разработки |

## 3. Продающие тексты (лендинги, кратко)

### Старт
**Заголовок:** Claude Code с нуля: ИИ-ассистент, который сам делает файлы, сайты и отчёты — без программирования
**Подзаголовок:** 4 недели, 12 уроков, 5 готовых проектов. Для тех, кто никогда не открывал терминал.
**Вы сможете:** установить и настроить Claude Code · создать сайт-визитку, бота-парсер, отчёт из Excel · разбирать большие документы за минуты · не ломать файлы (безопасный режим) · ставить ИИ задачи так, чтобы получать результат с первого раза.
**CTA:** Попробовать бесплатный урок.

### Практик
**Заголовок:** Claude Code для работы: настройте ИИ-среду, которая выполняет задачи по вашим стандартам
**Подзаголовок:** CLAUDE.md, skills, MCP, хуки, git-процесс. 6 недель, 18 уроков, 4 проекта в портфолио.
**Вы сможете:** вести проекты с памятью и правилами · подключить базы, Notion, GitHub, браузер через MCP · автоматизировать проверки хуками · работать в ветках/worktrees · планировать и проверять работу агента.

### Профи
**Заголовок:** Claude Code на уровне команды: субагенты, CI/CD, SDK и безопасность
**Подзаголовок:** 8 недель, 24 урока, внедрение в вашей компании.
**Вы сможете:** строить мультиагентные пайплайны · запускать Claude Code в GitHub Actions/CI · писать своих агентов на Agent SDK · управлять правами, секретами, стоимостью · измерять ROI и внедрять стандарты в команде.

## 4. Воронка
1. **Трафик:** Telegram-канал/YouTube (короткие кейсы «задача → результат за 5 мин»), SEO-статьи, партнёрки, вебинары.
2. **Лид-магнит:** «Шпаргалка 30 команд Claude Code» + 3 бесплатных урока.
3. **Прогрев (5 писем/сообщений):** кейс → ошибки новичков → демо → отзывы → оффер с дедлайном.
4. **Продажа:** лендинг + вебинар-демо (60 мин) + консультация для дорогих продуктов.
5. **Апсейл:** на 3-й неделе Старта — оффер на Практик со скидкой 20%; после Практика — на Профи.
6. **Ретеншн:** клуб, обновления курса при выходе новых функций.

## 5. Запуск потока (8 недель)
| Недели | Задачи |
|---|---|
| −8…−6 | Запись 30% уроков, лендинг, лид-магнит, платёжка |
| −6…−4 | Трафик на лид-магнит, 300+ лидов |
| −4…−2 | Вебинар-демо, предпродажа первому потоку (ранняя цена) |
| −2…0 | Чат студентов, онбординг, установка ПО |
| 0…N | Обучение, еженедельные Q&A, сбор отзывов |
| N+1 | Выпуск, сертификаты, кейсы, оффер на следующую ступень |

## 6. Работа с возражениями
| Возражение | Ответ |
|---|---|
| «Я не программист» | Курс «Старт» — без кода; всё решается формулировкой задачи |
| «Всё есть в документации» | Документация — справочник; курс — отобранный путь, готовые шаблоны и разбор ошибок |
| «Дорого/подписка сервиса» | Расчёт экономии часов; практики окупают курс за 1–2 задачи |
| «Устареет» | Обновления бесплатно в течение 12 мес. |
| «ИИ заменит» | Научитесь им управлять — это навык №1 следующих лет |

## 7. Юридическое и риски
- Договор-оферта, политика возврата, согласие на ПДн, лицензия на материалы (личное использование).
- **Доступность сервиса:** Claude/Claude Code доступны не во всех странах и регионах. Проверьте актуальный список поддерживаемых стран у провайдера и не продавайте и не рекомендуйте способы обхода ограничений. Для аудитории из неподдерживаемых стран предлагайте формат «теория + локальная практика» либо ограничьте продажи.
- Не обещайте доход: только навыки и измеримые результаты занятий.
- Не копируйте чужие материалы и официальную документацию; используйте цитаты с источником и свои примеры.
- Данные клиентов в практиках — только демо или обезличенные.
- Для корпоративных клиентов: NDA, политика данных, пилот на непродуктивных данных.

## 8. Метрики
Конверсия лид→покупка 3–7%; доходимость уроков >50%; NPS >50; выполненные практики >60%; апсейл между ступенями 15–25%; возвраты <5%.
