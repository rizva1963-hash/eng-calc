# Курс 1. Claude Code: Старт (для начинающих)

## 1. Паспорт
- **Аудитория:** предприниматели, маркетологи, аналитики, инженеры, студенты — без опыта программирования.
- **Вход:** компьютер (Windows/macOS/Linux), аккаунт с доступом к Claude Code, английский на уровне «читаю с переводчиком».
- **Результат:** уверенно ставит задачи агенту, работает безопасно, делает 5 проектов: сайт-визитка, отчёт из Excel/CSV, разбор PDF/документов, автоматизация папки, личный «помощник по проекту».
- **Формат:** 4 недели × 3 урока (видео 10–20 мин) + практика 30–60 мин + 1 Q&A в неделю. Офлайн: 1 день (8 ч).
- **Метод:** «Цель → Контекст → Ограничения → Проверка» (формула промпта ЦКОП), безопасность по умолчанию.

## 2. Программа

### Модуль 1. Знакомство и установка (неделя 1)
**Урок 1.1. Что такое Claude Code и чем он отличается от чата**
- Чат vs агент: читает файлы, запускает команды, правит проекты.
- Что может и чего не может. Реальные примеры.
- Практика: 3 задачи «чат или агент?».

**Урок 1.2. Установка и первый запуск**
- Терминал за 15 минут: cd, ls, mkdir, открытие папки.
- Установка Claude Code (актуальный способ из документации) `[СВЕРИТЬ]`, вход в аккаунт, проверка `claude --version`.
- Практика: создать папку `my-first-project`, запустить `claude`, попросить создать `hello.md`.

**Урок 1.3. Интерфейс и базовые команды**
- Ввод, история, `/help`, `/clear`, `/compact`, `/cost`, `/model`, выход.
- Режимы разрешений: спрашивать / автоправки / план (переключение Shift+Tab) `[СВЕРИТЬ]`.
- Практика: пройти квест «5 команд».

### Модуль 2. Как ставить задачи (неделя 2)
**Урок 2.1. Формула ЦКОП**
- Цель, Контекст, Ограничения, Проверка. Разбор плохих/хороших промптов.
- Практика: переписать 5 промптов.

**Урок 2.2. Режим плана и итерации**
- Всегда сначала план для больших задач; уточняющие вопросы; откат.
- Практика: «Сайт-визитка за 20 минут» (Проект 1).

**Урок 2.3. Безопасность и контроль**
- Что нельзя давать (пароли, ключи, личные данные), рабочая копия проекта, резервные копии.
- Как читать запросы разрешений. Откат (checkpoint/`/rewind`, git для новичка) `[СВЕРИТЬ]`.
- Практика: намеренно «сломать» файл и восстановить.

### Модуль 3. Работа с файлами и данными (неделя 3)
**Урок 3.1. Документы: PDF, Word, Excel**
- Конвертация в Markdown (markitdown) перед чтением — экономия токенов.
- Резюме, извлечение таблиц, сверка версий.
- Практика (Проект 2): разобрать договор/ТЗ → конспект + список рисков.

**Урок 3.2. Таблицы и отчёты**
- CSV/Excel → анализ → график → отчёт HTML/PDF.
- Практика (Проект 3): отчёт по продажам из CSV.

**Урок 3.3. Автоматизация рутины**
- Переименование файлов, сортировка папки, массовая обработка.
- Практика (Проект 4): скрипт, который раскладывает «Загрузки» по папкам (с предварительным предпросмотром).

### Модуль 4. Память, шаблоны, финал (неделя 4)
**Урок 4.1. CLAUDE.md — память проекта**
- Зачем, что писать, `/init`, пример для личного проекта.
- Практика: написать CLAUDE.md для своего проекта.

**Урок 4.2. Готовые рабочие шаблоны**
- Библиотека 20 промптов (контент, анализ, письма, планы, учёба).
- Практика: собрать личную библиотеку.

**Урок 4.3. Итоговый проект и дальнейший путь**
- Защита проектов, карта развития → курс «Практик».
- Практика (Проект 5): «Помощник по моему делу» — проект с CLAUDE.md, данными и 3 автоматизациями.

## 3. Итоговый проект и оценка
**Требования:** папка проекта, CLAUDE.md, 3 выполненные задачи, отчёт «что сделано/проверено/ограничения», короткое видео-демо 3 мин.

| Критерий | Баллы |
|---|---|
| Постановка задач (ЦКОП) | 25 |
| Корректность результата и проверка | 25 |
| Безопасность (бэкап, права, данные) | 20 |
| CLAUDE.md и структура | 15 |
| Презентация | 15 |
Зачёт: ≥ 70 баллов → сертификат.

## 4. Тест (20 вопросов, фрагмент)
1. Чем агент отличается от чата? (файлы/команды/цикл действий)
2. Что значит «Ограничения» в ЦКОП? Приведите пример.
3. Когда использовать режим плана?
4. Что делать, если Claude предлагает удалить файлы?
5. Для чего CLAUDE.md?
6. Назовите 3 типа данных, которые нельзя передавать агенту.
7. Как проверить, что результат верный?
(остальное — по аналогии с уроками; ключи ответов в папке преподавателя)

## 5. Руководство преподавателя
**Тайминг урока 15 мин:** 2 мин цель → 8 мин демо вживую → 3 мин ошибки → 2 мин задание.
**Частые ошибки учеников:** не открыли нужную папку; нет доступа/лимиты тарифа; Windows-пути и политики PowerShell; слишком расплывчатые промпты; принимают результат без проверки.
**Правило:** каждое занятие — один видимый результат. Новичок должен «победить» в первые 20 минут.
**Поддержка:** чат, ответ ≤ 24 ч, еженедельный созвон, FAQ по установке (Windows/macOS отдельно).

**Оборудование:** ноутбуки участников, Wi-Fi, проектор, запасные аккаунты/доступ, раздатка (шпаргалка + чек-лист безопасности), заранее подготовленные данные (CSV, PDF, шаблон репозитория), 1 ассистент на 8–10 человек.

## 7. Комплект упаковки
- 12 видеоуроков, 12 шпаргалок, 5 шаблонов проектов, библиотека 20 промптов, тест, сертификат, чат, FAQ по установке.
