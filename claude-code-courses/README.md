# Пакет курсов «Claude Code» — 3 уровня

Готовая упаковка для продажи онлайн и офлайн.

| # | Курс | Для кого | Результат | Длительность |
|---|------|----------|-----------|--------------|
| 1 | **Claude Code: Старт** (`01-beginner.md`) | Новичок, не программист | Делает рабочие проекты, файлы, сайты, автоматизации «словами» | 4 недели / 12 уроков / 1-дневный офлайн |
| 2 | **Claude Code: Практик** (`02-intermediate.md`) | Разработчик, аналитик, технарь, фрилансер | Настроенная рабочая среда: CLAUDE.md, skills, MCP, хуки, git-процесс | 6 недель / 18 уроков / 2-дневный офлайн |
| 3 | **Claude Code: Профи** (`03-pro.md`) | Тимлиды, инженеры, владельцы продуктов, интеграторы | Агентные системы: субагенты, CI/CD, Agent SDK, командные стандарты, безопасность | 8 недель / 24 урока / 3-дневный офлайн |

Бизнес-часть: `00-business.md` — позиционирование, цены, продающие тексты, воронка, запуск, возражения, юридическое.

## Структура каждого курса
1. Паспорт (аудитория, результат, входные требования, формат)
2. Программа по модулям и урокам (цель → содержание → демо → практика → домашка)
3. Итоговый проект и критерии оценки
4. Тест / чек-лист аттестации
5. Руководство преподавателя (тайминг, типовые ошибки, как вести)
6. Офлайн-интенсив: расписание по часам, материалы, оборудование
7. Комплект материалов для упаковки (что записать, что раздать)

## Как пользоваться
1. Прочитайте `00-business.md` и выберите модель продаж (рекомендуется лестница: Старт → Практик → Профи).
2. Запишите уроки по программе. На каждый урок: скринкаст 8–20 мин + практика + шпаргалка 1 страница.
3. Перед записью **сверьте команды и функции с актуальной документацией** (docs.claude.com → Claude Code): продукт быстро меняется. Все места, где нужна сверка, помечены `[СВЕРИТЬ]`.
4. Офлайн: используйте расписания из раздела «Офлайн-интенсив» каждого курса.

## Важно
- Курс не аффилирован с Anthropic. Не используйте логотипы/название как «официальный курс». Формулировка: «Курс по работе с Claude Code».
- Доступность сервиса зависит от страны ученика — см. раздел «Юридическое» в `00-business.md`.
